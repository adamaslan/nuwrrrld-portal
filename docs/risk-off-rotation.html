What would change this read

Verified

The engine is internally coherent

All twelve inverse/leveraged mirror pairs in the universe resolved opposite as they must — SH bullish against UPRO bearish, SQQQ against TQQQ, SOXS against SOXL, and nine more. Since these track identical underlyings by construction, agreement would have proven the indicators were reading noise. None did.

Data gap

No sentiment reached any signal

Finnhub's news-sentiment endpoint returned HTTP 403 for every symbol requested. Every reading here is pure price and volume — no news, no fundamentals, no earnings dates. A name can score 100 the day before a catastrophic print.

Sample bias

This universe is a portfolio, not an index

The 933 tickers are a Yahoo portfolio export unioned with a partial large-cap seed — not the S&P 500, and there is no index-membership column to filter by. The 74.4% bearish figure describes this book. It is a reasonable proxy for a broad tape but is not a market-cap-weighted breadth measure, and its theme weights reflect prior collection interest.

Method

The score has nine values, so ties decide the ranking

Score is 50 + (bullish − bearish) × 12.5 over four booleans, so 24 stocks tie at 100 and the ordering above comes from the tiebreak — volume confirmation first, RSI headroom second — not from the engine. Treat the ten as an unordered set and use the raw columns to form your own view.

Coverage

Four tickers never resolved, and six sector ETFs are missing

BBBY and VSCO are delisted; BRK.B and BF.B failed because the database stores dot-notation share classes while the price API expects BRK-B. Separately, only 5 of the 11 SPDR sector ETFs are registered — XLK, XLF, XLV, XLY, XLP and XLRE are absent, as are SPY, HYG, LQD and UUP, so sector rotation had to be inferred from stock-level aggregation rather than read directly.

Scope

One bar, no backtest

This is a single daily close. Nothing here is validated against forward returns, no hit rate is claimed for the scoring model, and the defensive rotation described is a same-day cross-section — not a trend confirmed over weeks.
