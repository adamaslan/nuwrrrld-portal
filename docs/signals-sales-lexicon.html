Why this exists

The engine's real vocabulary — ConfluenceRanker, confidence_label, parameter grids, backtest hit-rate buckets — is accurate but not sellable. This is the translation table: one row per engineering term, its consumer-facing name, and why that name was chosen. Matched against the voice already shipped in components/landing/RiskSpotlight.tsx and the HOLD EM / FOLD EM verdict UI — plain-spoken, argument-driven, poker-themed — not invented from scratch.

Reading the timeline straight: no single codebase has ever absorbed all three lineages' best ideas. mcp-finance1 originated the grid, stalled at 4 categories. gcp3 forked internally into a lightweight feature-store and a separate kitchen-sink module that grew grids independently. ai-fin-opt2 solved historical scanning but never got confluence scoring. signals-app is the newest, most disciplined lineage, and still hasn't merged the historical-scan line. The "total possible calculations" below is a ceiling if all four lineages were unified, not a number any single running system produces today.

Why 211 ≠ 466: the table above counts distinct parameter configurations per category. Several categories emit more than one signal-state per configuration — e.g. a single BB(20, 2σ) config can independently fire upper-breakout, lower-breakout, %B-extreme, and band-ride — so the doc's own measured ceiling (466/bar, cited directly in signal-multiplication-analysis.md) sits above the raw config count. Both numbers are real; they answer different questions ("how many dials" vs. "how many things the dials can say").

Flag before using this copy

⚠ "Track Record" is not wired to any live endpoint yet.

Per homebase/docs/signal-robustness-status.md (2026-07-09): confidence calibration — feeding backtest hit-rates back into confidence_label — was built and tested in signals-app (branch feat/confidence-calibration, commit b494fd7, 35 tests passing) but was committed locally and never opened as a PR. The portal's confidence_label today is score-threshold-derived from gcp3, not hit-rate-calibrated. Don't claim "backtested confidence" in copy until that wiring ships and is confirmed live — verify with a fresh git log check on signals-app before using this term externally.
