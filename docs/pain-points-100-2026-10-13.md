# Portal pain points: 100 items across pipelines and slowness (2026-10-13)

**Follow-up, 2026-10-14:** PR #280 merged the card-date and hydration run-log
fixes (items 6, 52–54); PR #281 merged the public sample read path (items 25–26,
46–47). PR #285 adds the missing scheduled producer for `council_sample` and is
awaiting independent verification. The measurements below remain the October 13
snapshot; production behavior after those deployments needs a fresh run.

This is a read-only audit of `nuwrrrld-portal` at `1f739d9`, which is `main` after #276, #277 and #278. Items already fixed in those PRs are left out. The audit made no writes. The evidence comes from four sources:

- reading the code in this worktree;
- `gh run list` / `gh run view` on the last 200 Actions runs;
- read-only Neon queries (a `SET TRANSACTION READ ONLY` transaction, with `DATABASE_URL` sourced by name and never printed);
- `curl` TTFB measurements against production and the gcp3 backend, plus `modal app list` / `modal app history`.

Every number below comes from one of those reads. None is an estimate.

**Legend.**

- **Severity:** P0 means users or paper-capital correctness are broken now. P1 is a serious or silent failure. P2 is a real cost or risk. P3 is cleanup.
- **Size:** S is under 1 h, M is half a day, L is a day or more.
- **Surface:** pipeline, slowness, bug or reliability.
- **Sens:** ⛔ marks auth, session, CSRF, rate-limit, crypto, webhook or migrations. These go through `/fixy`'s confirmation gate, not an inline fix.
- **Unit:** the implementation unit in §2. `H` means human or ops work with no code unit.
