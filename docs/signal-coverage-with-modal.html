Signal architecture · 2026-08-18

Coverage stopped being
the expensive part.

The signal engine covers 54 ETFs because every covered ticker costs one AI narrative, and AI narratives are quota. Change the unit of coverage from a paragraph to a token card and the ceiling disappears — Modal computes the cards, the portal ranks them in SQL, and the model only writes sentences for the handful a human will actually read.

The compression

Five floats become one key

lib/grounding/taxonomy.ts already turns continuous indicator values into a fixed token vocabulary — it was written for grounding-pack retrieval, and it is, unchanged, the signal-card discretizer. Move the dials: the key underneath is the exact string toStateKey() emits.

toStateKey() TAXONOMY_V1
state_key

Joins straight to grounding_pack.state_key — every ticker gets cited, corpus-grounded rules for zero model calls. One of 486 reachable states at this horizon, which is why a vocabulary this small can describe a universe of any size.

The economics

Three lanes, three different ceilings

Coverage is capped today because all three of these are charged to one budget. Separated, only the third one costs anything — and it is the only one that needed to.

Pure functions over indicator fields. No network, no model, no key. Runs for every ticker in the universe on every bar, forever.

A deterministic score in code, a SQL ORDER BY for the ranking, and a join on state_key for cited rules. BUY/HOLD/SELL never needs a model.

unit — one indexed row
quota-bound

Explain

10 calls
ceiling: top ~100

Ten token cards per prompt, schema-locked output. Cards are tokens rather than floats, so batching is nearly free. The model writes prose and nothing else.

unit — one batched narrative

The model should never compute, never fetch, and never freestyle — it should classify, rank, and explain over pre-digested categorical inputs.

The thesis from nuwrrrld-small-model-engine.md, and the reason the quota ceiling stops being the binding constraint.

The split

What Modal adds, and what it must not touch

Modal is not a replacement for the GCP backend — that backend is healthy, and it serves its 54 ETFs in under a second. Modal is the lane nobody has built: per-stock indicators, computed in Python, fanned out nightly, failing loudly when they fail.

WorkHostCadenceCoverageCost
ETF signals — already computed GCP · Cloud Run daily 00:30 UTC 54 unchanged
Per-stock indicators — RSI, MACD, ADX, volatility Modal · pandas nightly EOD ~4,300 no quota
Card scoring, ranking, upsert Portal · Neon on ingest all rows no quota
Tier-0 grounding join Portal · SQL on read all rows no quota
Top-N batched explanations Portal · OpenRouter 00:10 UTC ~100 10 calls

The two universes never overlap: GCP owns ETF rows, Modal owns stock rows, and ticker_cards.source keeps provenance unambiguous. That separation is what makes a second RSI implementation safe — the two engines are never asked about the same symbol, so their numbers can never contend for one row.

The night

One pass, ordered by what the clock is worth

The schedule is the design. OpenRouter's free tier resets at UTC midnight, so the batch work runs when the allowance is freshest and leaves the rest of the day to questions a user is actually waiting on.

00:00
OpenRouter

Daily free-tier quota resets

Observed directly: a 429 reset at 2026-08-19T00:00:00Z. Everything below is positioned relative to this moment.

00:05
Modal · hydrate_universe_eod

Fan out the universe, post cards back

Chunks of ~100–200 symbols, pandas indicators, per-symbol status rows so one delisted ticker fails as data rather than as a run. Posts to the portal — never writes Neon directly.

00:08
Portal · /api/pipeline/hydrate-universe

Discretize, score, upsert, rank

Calls toStateKey(), applies the deterministic scorer, and upserts ticker_cards. A newer bar replaces an older one; partial data never overwrites a complete same-day card.

00:10
Scheduler · precompute-ai

Spend ten calls on the top of the ranking

The only quota-bound step of the night, running against the freshest possible allowance. quotaExhausted stops the job rather than spilling into the interactive budget.

The guardrails

What has to stay true

ContractWhy it exists
Modal never writes Neon Validation, idempotency and the auth boundary stay in one place — the portal. Modal holds a push secret and a vendor key, never the database.
The model key stays portal-side Modal triggers precompute over HTTP and nothing more, so there is never a second long-lived copy of OPENROUTER_API_KEY.
Missing inputs lower data_quality Absent indicators bucket into neutral-looking tokens. Without an explicit missing_fields column, "neutral because the market is quiet" and "neutral because the fetch failed" become the same card.
Every interpretation is versioned TAXONOMY_V1 and the score version travel with each row, so a moved threshold can't silently put two incompatible cards in one ranking.
Prose failing never breaks the card If the model output fails schema validation the score, action, tokens and citations still render. Only the sentence is missing.
Exactly one scheduler owns the nightly run A GitHub Actions workflow and a Modal function currently both fire 10 0 * * * at the same endpoint. Two runs double-spend the quota for identical output.
