Grounding pack is empty — two causes

Needs a decision

The corpus isn't here. corpus/ holds two files its own README marks as samples; the real trader Q&A set lives in a sibling repo's DOCS_ROOT that isn't checked out. The README explicitly warns against copying it sight-unseen, and compiling from the engineering docs that are present would fill Tier 0 with confident, verbatim-cited, irrelevant rules — worse than empty, because it looks grounded.

The quota is spent. Extraction costs one model call per chunk against a 50/day free-tier ceiling, currently at zero remaining. A real corpus of a few hundred chunks can't compile in one day on the free tier at all — it needs credits, batching, or a multi-day incremental run. Worth planning before the migration, not after.

Needs you to decide whether to migrate the corpus and how to pay for extraction. The compiler itself is verified working end-to-end.

Yours to decide. It's a GCP project and IAM-scope choice, not a code fix.
