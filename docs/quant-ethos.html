Deterministic first. The model narrates.

Every number on this desk is computed by rules before a language model sees it. The model's job is to explain a number it was handed — never to produce one. That single constraint is what the rest of the engine is built to protect, and most of the machinery below exists because it was violated once and something quietly lied.

The stack

Six layers, bottom to top. The model only appears at layer five. Everything under it is arithmetic you can recompute by hand from the same inputs and get the same answer.

L1

Indicator math

EMA, Wilder smoothing, RSI, MACD crossover, ADX, and a rolling volatility percentile — hand-ported from the Python job that also writes to this table, and pinned numerically against captured reference values so the two hosts cannot silently disagree.

RSI 14  ·  MACD 12/26/9  ·  ADX 14  ·  vol window 20

L2

Confluence

Indicators vote −1 / 0 / +1; agreement is the absolute net over the vote count. A trending tape makes agreement mean more, so a strong ADX scales it up — capped, because a confidence above 100% is a bug, not a conviction.

ADX ≥ 25 → agreement × 1.25, clamped to 1.0

L3

Three-state signal

A direction per timeframe with its own confidence and cited evidence, plus an alignment score across timeframes and a named divergence pattern. Three states, not two: neutral is a real answer, and collapsing it into buy-or-sell is how a flat tape becomes a fabricated conviction.

timeframes 1D · 5D · 1M · 3M · 6M · 1Y

L4

Portfolio scoring

The watchlist is the portfolio. Cards are weighted into one score and grade, with coverage reported beside it rather than folded into it — so “we don't know yet” never renders as “this is bad.”

weights signal .45 · direction .30 · diversification .25

L5

The council

Six seats argue one position: two horizons, a devil's advocate, a macro seat, a quant classifier, and a chair that synthesises. Each answers in four labelled fields, and a repair loop re-asks any seat that drifts out of format rather than shipping prose that looks like a verdict.

seats T1 · T2 · RISK · MACRO · QUANT · CHAIR

L6

The judge

A second model grades every verdict on five criteria, blind to the outcome — no realised price, no resolved result, no date. A judge that can see the answer grades hindsight. Its own scores are gated on a gold set before any of them are allowed to publish.

criteria grounding · falsifiability · consistency · specificity · calibration  ·  max 10

Grading the grader

An LLM judge is only worth having if it can be caught being wrong. So the judge is run against a gold set of hand-scored verdicts every time, and a run that disagrees with the gold set is discarded whole — including its good scores.

Agreement threshold0.80 Below it, nothing publishes.The only defence against silent judge drift when the free-tier chain swaps a model out from under the harness.

Empty gold setfail No gold set is a hard fail, never a pass.A judge with nothing to check it against is unfalsifiable, which is worse than one known to be poor.

The gate is not decorative. On this run the judge scored a deliberately mediocre fixture 10 / 10 against a gold score of 5 — agreement 50%, below the threshold, so the entire run's scores were thrown away and nothing reached the scorecard. That is the pipeline working. It is also a standing finding: with a two-case gold set, one disagreement is 50%, so the set is too small to distinguish a drifting judge from an unlucky one.

What “reachable” had to start meaning

The weekly audit used to check that a seat's model existed in the catalog and was priced at zero. Three separate failures passed that check: a seat quietly running a paid model, a seat on a $0 model that returns 403 — only available on agentic harnesses, and two seats on $0 models that answer 429 to every request including the retry. Existence and price are not reachability. The audit now sends a real one-token call to every seat, and counts an unreachable seat as degraded.

The fallback chain behind the seats is five deep across four vendors, and it now excludes specialist models by pattern — a code model, a safety classifier, and an audio preview all answer a ping perfectly happily, and a seat that fell through to one would get a code completion where a trader's outlook belongs. The chain's depth is only real if every rung can do the job.

Degradation ladder

When something upstream is missing, the engine walks down this ladder in order. It never skips to the bottom, and it never steps off the end into a plausible-looking guess.

  1. Upstream, freshThe preferred path answers the contract. It wins whenever it can.
  2. Upstream, shape-checkedA 200 carrying the wrong shape is treated as a miss, not coerced. A drifted payload once became “score 0, Grade F” for every user — a wrong answer that looked like a real one.
  3. Local computationThe portal computes the answer from data it already owns, and says so in a response header. An unlabelled substitute is a silent swap.
  4. Cached, with its ageStale is servable. Stale while pretending to be fresh is not.
  5. Honest unavailableA terminal, explicit “no answer” — never a narrative generated over an empty grounding block.

The ethos

Seven rules. Each one is here because breaking it cost something real, and each carries the bill.

  1. Blocked is not failed.

    A feature whose dependency is unmet was not exercised; it did not fail. Collapsing the two produces a wall of red that nobody reads, and hides the one row that is genuinely broken. A rate-limited call is blocked. A missing backend URL is blocked. A wrong answer is a failure.

    Cost when broken: 53 of 59 features reported as one indistinguishable state.

  2. Degrade to a lesser state, never to a fabrication.

    Every fallback must be a smaller claim than the thing it replaces. A model handed no grounding must refuse, not improvise — the failure mode of a confident sentence with nothing behind it is indistinguishable from the real thing, which is exactly what makes it the worst available outcome.

    Cost when broken: a per-ticker chat that 503'd for every user, for as long as the feature existed.

  3. Say which path answered.

    Upstream, local, cached, precomputed — the response carries its own provenance. Three distinct faults once rendered one identical string, and that is what let an outage run for 47 days while looking like a slow day.

    Cost when broken: 47 days.

  4. Report coverage; never fold it into the score.

    A portfolio with 3 of 20 tickers covered must not score low for it. “We don't know” rendering as “this is bad” is the same trap as a fabricated answer, one layer up, and it is the more tempting of the two because it looks rigorous.

    Cost when broken: Grade F for every user, from missing data.

  5. A metric that cannot be wrong is not a metric.

    The judge is gated on a gold set; hit rates are suppressed under thirty resolved picks; an empty gold set fails closed. Anything unfalsifiable is removed rather than reported, because a number nobody can challenge gets trusted exactly as much as one that earned it.

    Cost when broken: a scorecard that only ever agrees with itself.

  6. Own the contract rather than wait for it.

    When an upstream route does not exist, the portal implements it locally and keeps calling upstream first, so a later deploy takes over with no code change. Waiting for a fix that is “ready” is a decision being made by nobody.

    Cost when broken: two features dead for weeks while a fix sat undeployed.

  7. A test fixture must leave no trace.

    The sweep writes a synthetic ticker and removes it in the same run. It previously removed before adding — filesystem order, not intent — so it left its own test data behind and then reported the feature that data broke.

    Cost when broken: a sweep failing a feature it had sabotaged itself.
